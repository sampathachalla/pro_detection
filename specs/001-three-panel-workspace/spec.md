# Three-panel handwriting workspace

Users can upload or capture a handwriting photo from Data, or select a previously uploaded test image from the grid below. Result occupies the left side and shows the selected image or its annotated result. Suggestion displays mistakes and proposed corrections for that image.

On desktop, Result, Data and Suggestion share the full available viewport width below the existing header. Each panel can collapse independently and reopen without losing the selected image. On narrow screens, all panels are available as full-width stacked sections. Use the supplied screenshot as a reference for the annotated preview and analysis content.
